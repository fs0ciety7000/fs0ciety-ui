# fs0ciety — M2 `@fs0lab/css` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `@fs0lab/css` 0.1.0: the cascade-layered stylesheet every fs0ciety component and app relies on — reset, base typography and focus, a small utility set, and the CSS-only signature effects (scanlines, RGB bleed, grid, glitch hover, cursor, sweep) — with reduced-motion, contrast-more and forced-colors handled, verified by unit tests, axe and visual snapshots in three themes.

**Architecture:** Source files under `packages/css/src/`, one per layer, each wrapping its rules in `@layer fs.<name> { … }`. `scripts/build.mjs` bundles them with lightningcss (resolving `@fs0lab/tokens/css` from the workspace) into `dist/fs.css` (tokens included) and per-layer files `dist/{reset,base,utilities,effects}.css` (each starting with the layer-order statement, tokens not included). Components (M3+) will add `src/components/*.css` in the `fs.components` layer. A static specimen page (`test/e2e/specimen.html`) exercises everything; Playwright runs axe, computed-style checks and screenshots against it inside the official Playwright Docker image so snapshots are reproducible.

**Tech Stack:** lightningcss 1.33, @fs0lab/tokens (workspace), Vitest, @playwright/test 1.64 + @axe-core/playwright 4.14 (image `mcr.microsoft.com/playwright:v1.64.1-noble`), http-server 14 (specimen server), @fontsource-variable/martian-mono + inter-tight 5.3 (test fixtures only; the shipped font comes in M9).

**Spec:** `DESIGN.md` (Principes, Typographie, Espacements…, Motifs signature, Composants « Socle commun », Mouvement, Accessibilité, À éviter), `docs/brief.md`, `CLAUDE.md`. Previous milestone: `docs/superpowers/plans/2026-11-05-m1-tokens.md` (token names).

## Global Constraints

- Node `>=22`, TypeScript `^6`, ESM, Biome formatting. Commit messages: Conventional Commits.
- Layer order, declared first in every distributed file: `@layer fs.reset, fs.tokens, fs.base, fs.components, fs.utilities, fs.effects;`
- Styles read **semantic** tokens only (`--fs-bg`, `--fs-text`, `--fs-line-strong`, `--fs-space-4`, …). No `--fs-color-<hue>-<step>` primitive and no literal color (hex, `rgb(`, `oklch(`, named colors other than `transparent`/`currentColor`/system colors) anywhere in `packages/css/src`. Translucent variants use `color-mix(in oklch, var(--fs-<role>) N%, transparent)`.
- Class prefix `.fs-`; effects are opt-in attributes `data-fs-fx="scan bleed grid glitch-hover sweep"` (space-separated, matched with `~=`); the cursor is `.fs-cursor`.
- Selectors stay low-specificity (`:where()` for reset and base element rules) so consumers can override without `!important`. No `!important` except inside `@media (prefers-reduced-motion: reduce)` and `(forced-colors: active)` overrides.
- `prefers-reduced-motion: reduce` → no animation, no transition longer than 150 ms, end states shown. `data-fs-motion="paused"` on any ancestor pauses every fs animation (`animation-play-state: paused`). `prefers-contrast: more` → `--fs-line` becomes `--fs-line-strong`, `--fs-text-subtle` becomes `--fs-text-muted`, decorative effects removed. `forced-colors: active` → effects removed, focus uses `Highlight`.
- Focus: `:focus-visible { outline: var(--fs-stroke-focus) solid var(--fs-focus-ring); outline-offset: 2px; }`, `scroll-padding-top` honoured via `--fs-scroll-offset` (default `0px`).
- No browser targets lowering: lightningcss targets Baseline 2024 (`chrome 120, firefox 121, safari 17.2`) so `oklch()` and `color-mix()` are kept as written.
- Every CSS entry exported from `package.json` has a `types` condition pointing at an empty `export {};` `.d.mts` (TS 6 `noUncheckedSideEffectImports`, lesson from M1).
- Packages other than `@fs0lab/css` (and the already public `@fs0lab/tokens`) stay `"private": true`.

## Review Focus

1. **Override-ability**: a consumer rule `a { color: red }` written outside any layer must beat fs base styles (unlayered > layered), and `.my-card { padding: 0 }` must beat `.fs-` utilities only if the consumer chooses — test that base element rules are in `:where()` (specificity 0). → Task 2.
2. **Nested theme + contrast-more**: inside `<div data-fs-theme="light">` within a night page, under `prefers-contrast: more`, `--fs-line` resolves to the light theme's `line-strong`, not night's. → Task 2 (unit) and Task 5 (computed style).
3. **Reduced motion really stops everything**: with `reduce`, `getComputedStyle(el).animationName` is `none` for every `[data-fs-fx]` and `.fs-cursor` element, and the RGB bleed stays visible but static. → Tasks 4 and 5.
4. **Effects never hide content or eat clicks**: overlay pseudo-elements have `pointer-events: none`, sit under focus rings, and text inside a `scan` container still passes axe contrast. → Tasks 4 and 5.
5. **Package works for a consumer**: `import "@fs0lab/css"` type-checks under TS 6 and resolves to a single file that already contains the tokens; `@fs0lab/css/effects.css` works alone after the tokens. → Tasks 1 and 6.

### Task 4: Signature effects and motion preferences

**Files:** Modify `src/effects.css`. Create `test/effects.test.ts`.

Effects (values from DESIGN.md « Motifs signature » and D · Motion; colors via semantic roles):
- `[data-fs-fx~="scan"]`: `position: relative; isolation: isolate`; `::after` overlay `inset: 0; pointer-events: none; z-index: 0` with `repeating-linear-gradient(0deg, color-mix(in oklch, var(--fs-link) 5%, transparent) 0 1px, transparent 1px 3px)`; hidden by default in the light theme (inside and on `[data-fs-theme="light"]`, and in the OS-light fallback scope). Children get `position: relative; z-index: 1` via `[data-fs-fx~="scan"] > *` so text and focus rings sit above the overlay.
- `[data-fs-fx~="sweep"]`: a 60px band (`linear-gradient(180deg, transparent, color-mix(in oklch, var(--fs-link) 7%, transparent), transparent)`) translating top → bottom, 5 s linear infinite (`::before`, `pointer-events: none`).
- `[data-fs-fx~="bleed"]`: `text-shadow: -2px 0 color-mix(in oklch, var(--fs-cable-1) 85%, transparent), 2px 0 color-mix(in oklch, var(--fs-link) 85%, transparent)`; jitter keyframes `fs-bleed-jitter` 4 s `steps(1)` infinite reproducing D (0/88/100 % rest, 90 % −6 px / +5 px 1 px, 93 % +3 px / −4 px). Static shadow kept under reduced motion.
- `[data-fs-fx~="grid"]`: background with minor 8px lines `color-mix(… var(--fs-line) 12% …)` and major 64px lines at 35 %.
- `[data-fs-fx~="glitch-hover"]`: on `:hover` / `:focus-visible`, `transform: translateX(-2px); box-shadow: 4px 0 0 var(--fs-link), -4px 0 0 var(--fs-cable-3)` with `transition: transform var(--fs-duration-instant) steps(2), box-shadow var(--fs-duration-instant) steps(2)`.
- `.fs-cursor`: inline-block caret (`0.6em × 1em`, `background: currentColor`, `vertical-align: text-bottom`), blinking 1 Hz with `steps(1)`, `aria-hidden` expected in markup (documented in README).
- Preferences (in `fs.effects`):
  - `@media (prefers-reduced-motion: reduce)`: every animation `none !important`, `glitch-hover` transitions/transform/box-shadow off, `sweep` hidden, cursor solid.
  - `[data-fs-motion="paused"]` (and descendants, pseudo-elements included) → `animation-play-state: paused`.
  - `@media (prefers-contrast: more)` and `@media (forced-colors: active)`: `scan`, `sweep`, `grid` overlays removed, `bleed` text-shadow removed, `glitch-hover` reduced to nothing.
